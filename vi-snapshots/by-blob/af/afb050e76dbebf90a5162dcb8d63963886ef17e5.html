Controller API.lvlib:Controller API.lvclass:Start Controller.vi

This starts the controller that runs in the background to monitor running measurements and manage available resources. The path that is supplied to this method specifies the location of the configuration file. If it is not absolute, it will be appended to the disk location of this method. If the file does not exist at the specified location, it will be created using default settings.
